# Data licence

The model replies and memories in `runs/` and the tables in `results/` quote and are derived from BEAM
(Mohammad Tavakoli and colleagues, *Beyond a Million Tokens: Benchmarking and Enhancing Long-Term Memory
in LLMs*), which is released under the
[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) licence.
They are released here under the same licence.

This repository holds no copy of the benchmark itself. `scripts/fetch_data.sh` downloads the BEAM-100K
split from [huggingface.co/datasets/Mohammadta/BEAM](https://huggingface.co/datasets/Mohammadta/BEAM).

The code is under the MIT licence in `LICENSE`.
